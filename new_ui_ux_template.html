03 — Catatan Proyek

Empat proyek aktif yang terus dikembangkan secara bertahap

FN-01

2026 · aplikasi web · downloader

WavyDL

Layanan pengunduh media yang mampu mendeteksi jenis tautan secara otomatis. Mendukung Instagram, TikTok, Facebook, Spotify, Reddit, dan platform lainnya. Sistem akan memilih format video, foto, atau audio yang tepat secara presisi, menyusun album carousel, serta mengekstrak audio tanpa kompresi ulang.

  • Node.js
  • API Integration
  • 12+ Platform

FN-02

open source · fondasi bot whatsapp

Amira Bot Base

Kerangka dasar (*starter kit*) bot WhatsApp yang dirancang untuk mempermudah alur kerja pengembang. Memiliki struktur kode yang bersih, rapi, dan modular, lengkap dengan sistem penanganan perintah (*command handler*), penanganan peristiwa (*event handler*), serta sistem plugin. Dikembangkan di bawah ZanixonGroup.

  • Node.js
  • Baileys
  • Open Source

FN-03

2026 · aplikasi web · musik

Mirasvara

Layanan pengunduh trek Spotify ke format MP3 secara praktis. Cukup tempelkan tautan lagu untuk mendapatkan berkas audio berkualitasi tinggi (128/320kbps) yang telah dilengkapi metadata lengkap seperti nama musisi, judul, dan sampul album. Dilengkapi pula dengan dokumentasi API untuk pengembang.

  • Spotify API
  • MP3 Audio Processing
  • API Docs
